# Identity Kit & Visual Tokens

## Typography
* **Primary / Display**: Inter Tight (or Inter bold display variants)
* **Body / Interface**: Inter (clean, neutral sans-serif)
* **Monospace / Code**: JetBrains Mono / Geist Mono

## Color Palette
* **Deep Base**: `#0F172A` (Slate 900)
* **Subtle Canvas**: `#F8FAFC` (Slate 50)
* **Accent & Interactive**: `#059669` (Emerald 600) / `#10B981` (Emerald 500)
* **Muted Editorial Text**: `#475569` (Slate 600)
* **Border Lines**: `#E2E8F0` (Slate 200)

## Editorial Style Statement
Calm, evidence-first technical editorial voice. Minimal fluff, concrete technical metrics, and verified running code over descriptive claims.
