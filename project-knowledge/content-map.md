# Content Map & Site Architecture

* **`/` (Home)**: High-level positioning, primary engineering proof points, and quick CTAs.
* **`/chat` (AI Qualification)**: Streaming LLM conversation interface using Claude 3.5 Sonnet, scroll-lock retention, and mid-stream abort control.
* **`/playground` (A11y Foundations)**: Hand-rolled W3C accessible UI primitives (Focus-trapped Modal, Roving Tabindex Tabs, Disclosure).
* **`/identity` (Design System)**: Public typography pairings, color swatches, and editorial guidelines.
* **`/images` (Asset Curation)**: Architecture blueprints, verified screenshots, and visual evidence log.
* **`/dashboard` & `/settings`**: Project status, configuration, and monitoring scaffolds.
* **`/health`**: Edge server runtime health check.
